# /check：按证据审查现有工程

默认只读。审查对象是当前项目承诺和实际风险，不是项目与某套参考仓库的相似度。

## 建立证据范围

记录仓库/分支/提交或工作区状态、检查范围、配置环境与可访问资料。读项目指令、依赖锁、启动入口、部署配置、关键服务与测试；不要读取或输出真实密钥值。

沿一个真实路径追踪：触发源→身份与输入→受理/调度→执行引擎→模型/工具→状态与结果→调用者。对图工作流追踪节点、边、状态写入与 checkpointer；对插件宿主追踪注册、拦截、调用、卸载和清理；对托管平台确认实际连接与配置，不只看安装包。

`rg` 搜索用于找线索，不是证明缺陷。搜不到 `outbox` 或 `checkpoint` 不代表缺少可靠派工/恢复，可能由引擎历史、事务日志、云服务或不同名称代码提供。生成代码、动态注册或托管设置无法访问时，列为未知并说明核验办法。

## 覆盖与结论分开

完整审查遍历 [能力地图](capability-map.md)；局部审查只覆盖受影响项，明确未审范围。适用项分为：

- **已验证**：实际接线与相关测试/运行证据支持承诺；注明证据层级。
- **已发现缺陷**：有可说明的触发条件、真实路径和影响。
- **部分覆盖**：已有机制，但某项承诺或故障分支未覆盖。
- **未知/未验证**：材料不足或无法安全运行检查。
- **不适用**：没有触发条件，附理由。

测试缺失与行为缺陷分列。“未看见测试”不直接等于“实现错误”；README、依赖包、配置字段只是线索。一个入口通过不代表其他节点、工具、租户和管理入口通过。

## 优先追踪的边界

从项目风险中选择，不机械执行全部故障注入。

| 边界 | 核验问题 |
|---|---|
| 受理与派工 | 成功返回后退出是否丢任务？两个持久系统之间是否有未补偿的提交窗口？ |
| 重复与并发 | 重复消息/用户重试/并行节点怎样裁决？进程内锁是否被误当成跨副本锁？ |
| 外部副作用 | 成功后本地记录前退出会怎样？超时是否被误判为未执行？同意图与新意图怎样区分？ |
| 图/工作流恢复 | 从哪里重入？节点前半段、成功并行分支、子图、interrupt 前操作会不会再运行？ |
| 身份与资源 | 客户端/模型自报身份是否成为权威？事件、记忆、产物、工具和后台任务是否保持权限范围？ |
| 执行控制 | 重试是否叠乘？恢复是否重置预算？暂停是否占槽？取消后未决动作是否仍被跟踪？ |
| 变更与输出 | 旧快照/消息能否被新代码理解？断线/慢客户端是否影响执行？检查器是否误触真实写操作？ |
| 操作提交 | 暂停、继续、取消和完成的必要事实能否共同成立？丢失唤醒、重复回复或旧执行者清理会怎样？ |
| 时间合同 | 告警阈值与硬截止是否混淆？排队、等待、子任务和恢复后是否重置或超过允许时间？ |
| 业务收敛 | 已受理是否被当成最终完成？本地成功后下游变化、重复/乱序通知怎样核对修正？ |
| 观察生命周期 | 授权过期/撤销是否影响既有连接？历史已清理时会否静默丢事件或重做任务？ |

技术判定参照相关参考文件，核对项目锁定的框架版本。尤其检查 SDK 默认重试、持久化模式、动态权限和模型切换，不凭记忆套最新接口。

## 报告格式

先列风险最大的确定发现，再列部分覆盖和待验证问题。每项提供：

> **ID / 严重程度 / 置信度 / 能力 ID**
>
> **位置与证据**：文件行号、调用路径、配置或输出；无法读代码时引用已给材料。
>
> **触发与后果**：现有行为在什么条件下违反哪项承诺，受影响范围。
>
> **改进选择**：最小修复、可复用的框架能力、代价与替代方案。
>
> **验证方法**：如何复现或反证，修复后应观察什么。

严重程度按影响分：P0 已有紧急业务/数据/越权风险；P1 对当前使用方式构成重大缺陷；P2 常规可靠性或交付缺口；P3 维护建议。结合频率、范围、暴露条件与补偿措施，不按关键词自动定级。未经实证不要说“生产正在泄漏/重复扣款”。

报告包含适用性矩阵、已运行检查、未运行原因、主要保障与残余风险。默认不用总分；用户要评分时解释分母、权重、证据层级，未知不算通过。

存在工程计划时按 [证据工作流](evidence-workflow.md) 对照承诺与实际入口；无计划也可从当前产品承诺建立最小映射。故障复现按适用性观察持久事实、外部效果、资源释放及累计消耗，不仅判断是否返回成功。

## 验证与结束边界

先检查命令是否连接真实账户、发消息、计费、改远程数据或执行迁移。可在已确认的隔离环境复现；不在真实系统杀 Worker、重放写工具、批量恢复或回滚发布。

紧急缺陷应给具体止损建议与证据；`/check` 不授权执行生产止损。修复建议与实际修复分开。用户已同时要求修复时进入 `/build`，否则交付报告后结束。
