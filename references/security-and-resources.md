# 安全边界、模型、上下文与资源

这些是按风险选取的合同，不是统一要求每个工具都双人审批、每个应用都上容器集群。

## 工具是请求，执行权在后端

工具定义可以来自本地函数、动态插件、MCP、图节点或远程服务。注册/发现协议只说明如何找到与调用，不自动证明可信。

按能力声明：输入/输出、权限与资源范围、是否写入、风险、超时、重试条件、操作身份、可核实方式，以及需要时的审批/网络/数据政策。字段组织形式自由，检查运行路径确实使用它们。

可信身份、组织、账户等来自认证上下文；模型可以提出目标与参数，后端按业务规则校验。不要把“模型不要越权”当控制。参数合法仍可能业务非法，输出 schema 合法仍可能包含不可信指令。

拒绝与错误也要留下适当记录，但避免把敏感失败参数原样写日志。错误应可区分业务拒绝、基础设施异常和未知结果，不用空字符串伪装成功。

## 凭据与数据最小化

明确谁能读 prompt、工具参数、历史、事件、日志、记忆、产物和导出。只给模型与调用者任务需要的信息，秘密在工具/宿主层注入；密钥不写仓库、镜像、公开事件或模型上下文。

环境配置与秘密分开，隔离开发/测试/生产凭据、轮换与撤权。真正测试入口必须绑定测试资源，不能因为变量名字有 TEST 就断言隔离。日志脱敏、错误堆栈和对象存储访问同样需要检查。

## 网络、文件与执行环境

外部 URL、浏览器导航、下载、webhook 和代码执行按信任边界治理：

- 对公网访问工具，校验协议、目的地、解析后的 IP 与每次重定向，覆盖 loopback/private/link-local/metadata 等相关范围；处理 DNS 变化和 IPv6。需要访问内网的业务采用明确授权的范围，不能一刀切禁掉必要能力。
- 不将内部凭据自动转发给其他源；限制方法、请求/响应大小、时间和跳转；必要时在出口代理/网络层执行政策，不能只依赖模型传参验证。
- 代码/插件/浏览器的文件系统、子进程、网络、CPU、内存、运行时间与凭据边界明确。容器不是天然强隔离，宿主挂载、提权、socket、凭据继承会改变实际能力。
- 读写产物需防路径穿越与越权引用；临时工作区、进程和连接在完成、取消、异常、插件卸载时清理。保留必要诊断证据，不能提前清除未决操作身份。

用户已授权的合法能力按实际政策提供；出现 sandbox denial 先判断范围与原因，不能把反复扩大权限或绕过保护写成通用自动恢复策略。

## 模型适配与调用合同

模型网关可以是一个适配模块，也可以是独立服务；不要求拆微服务。职责按需要包含 provider 路由、能力差异、超时/限流/熔断、结构校验、有界修复、usage 和版本记录。

内部协议要表达工具调用关联、结构化结果、拒绝、截断、取消、部分流与错误。不同 provider 的消息角色与并行工具支持可能不同，不能直接拼接一种协议用于全部模型。

fallback 改变的不只有价格，还包括工具/结构支持、数据传输目的地、区域、质量和安全策略。应使用允许的候选并经对应验证；故障时不能把敏感数据发送到未经批准的新供应商。repair 也计入预算，次数有界，保留适当的原/修后诊断信息。

## 上下文、记忆和 RAG

会话历史、执行恢复现场、可长期重用的记忆、外部检索结果分别建边界。

- 压缩/摘要服务于上下文容量，不能丢弃尚未完成的工具调用关联、审批依据、预算和关键业务事实。完整恢复数据可以存模型上下文之外。
- 记忆写入明确来源、用户/工作区范围、可信度、有效期、纠错、删除和冲突处理；模型推测不自动成为用户事实。
- 检索索引、缓存与输出同时遵守权限；授权应在合适的检索/取文路径生效，不能读出秘密后仅靠回答层过滤。
- 文档和工具结果是不可信输入，可能包含指令注入。引用来源不等于执行其命令；派生摘要与子 Agent 结果也不提升信任级别。
- 分支、fork、跨 Agent 共享记忆说明复制的是内容还是引用；权限变化、过期数据与删除如何传播。

## 并发、速率与预算

分别限制进入速率、在途数量、队列长度/年龄、单任务调用次数、上下文/输出规模、执行时长与费用。按用户、项目、租户、工具、provider 或系统选择实际需要的维度。

多副本总限额要由共享计量、服务配额或明确分配承担；进程内 semaphore 只限制本进程。崩溃后的容量回收、公平调度和高低优先级策略按场景设计。

预算声称“硬限制”时应能在动作前原子预留或提供等价最坏消耗上界，之后按实际 usage 结算，重复结果不会重复扣减。流中断/超时可能已计费，未知消耗不能直接归零。计量与结算失败要可修复。

估算值注明来源，金额用明确精度/币种规则。预算覆盖模型、工具、repair、fallback、子任务和重试；恢复或重开执行是否共享额度由业务意图决定，不能被无限重置。

达限行为需要产品合同：拒绝、排队、部分结果、降级或等待授权。不要自动提高用户额度、扩大模型权限或将无上限重试作为兜底。
