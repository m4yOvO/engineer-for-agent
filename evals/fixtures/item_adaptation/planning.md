# 实时演练助手：当前项目材料

请使用 /brainstorming 给出可以交给开发者执行的工程计划，结合这些需求决定设计与交付内容，只做规划。

产品是桌面应用内嵌的实时演讲练习助手，已经选择 Python 状态图执行层和本地 IPC。一个操作系统用户可以同时打开两个练习窗口，每个窗口最多一个当前讲解轮次；图中包含转写归整、只读参考资料检索、模型反馈和结果展示，不会操作其他业务系统。一次会话可能持续 45 分钟。用户可以随时打断并开始新轮，旧轮次的文本和迟到工具结果不能混入新轮。界面希望持续显示当前进度，断开后重新连接只需看到当前轮的状态和已生成内容，无须补齐中间进度事件。

隐私约束：转写文本、检索内容、模型输入输出与临时会话状态只能放内存，退出/崩溃后不恢复练习，会话结束释放；不得通过日志、Trace、checkpoint 或缓存悄悄持久化。用户明确点击导出时，才把选中的总结写入指定 Markdown 文件，写入失败必须保留之前的完整文件；需要说明覆盖选择及路径边界。这个导出是唯一允许的内容持久化路径。诊断可以记录不含内容的错误类别、持续时间及计数。可以向用户配置并同意的模型服务发送当前会话所需内容，凭据使用现有操作系统凭据库。

现有实现：前端已经提供窗口和轮次 ID；应用已有本地 IPC 路由、取消令牌及图调度适配器，目前只有接口草案，未完成集成，不能视为已验证。模型适配器提供流式文本与取消请求；供应商是否能停止已在途生成尚未核验。内置资料只读、无需远程写入。没有中央服务、跨进程任务队列或账号系统；后续是否引入云端协作未决定。

需要计划覆盖入口/图控制、存储、工具和模型结果、资源/隐私、观察和交付；请把具体实现职责、设计取舍、增量和验收讲清楚。可以给结构或伪代码，勿实现业务代码或联网验证。
