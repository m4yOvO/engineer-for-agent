# 两个独立项目的规划请求

请分别用 /brainstorming 给出可交给构建者的工程计划，重点包括数据、状态、调度和工具恢复的具体取舍。只规划，不实现代码；不能把未提供的部署事实写成通过。

项目 S1：个人离线文本摘要 CLI。本地模型、一个显式输入目录和输出文件；没有网络、多用户或跨进程恢复要求，中断允许重跑；输出不能未经许可覆盖。需要可维护、输入规模和运行时长有界。

项目 S2：已有托管持久工作流平台上的内部资料归档服务。平台合同已提供持久受理、队列/派工、活动重试、执行历史和版本路由，不要更换平台；未提供实际部署配置。用户上传一批资料，活动调用两种归档工具，某个成功后其他可能失败，最终应能查询每份资料的归档结果；通知是尽力送达，业务事实必须可查询。一个资料允许用户明确发起新归档版本；同一版本的恢复不能重复创建归档。归档服务提供稳定操作 key 防重及权威查询，期限待确认。需要跨天人工确认、取消、当前权限复核、旧任务升级兼容。现有业务库支持事务；当前没有正式表设计、状态/命令合同或恢复验收。请比较复用与需补充的责任，给出逻辑数据与查询/约束、状态转移、队列职责、工具事实关联及分阶段验收。
